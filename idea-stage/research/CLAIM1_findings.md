# Claim 1 实证发现：分层预算熔断的成本效应

> 科研产物（idea-stage/research/）。配套实验计划见 `../refine-logs/EXPERIMENT_PLAN.md` §Measured Results。
> 数据落盘：`ctf_agent/data/results/claim1/`（A1-A3 `_budget_off` + B1-B3 `_budget_on`，各 3 次重复）。
> 提取脚本：`ctf_agent/eval/benchmark.py`（token 字段由 `run.py` ContextVar 累计真实 `usage.total_tokens`）。

## 1. 研究问题

三级预算熔断（`scheduler/budget.py` 的 `BudgetBreaker`：全局预算 / 单题预算 / 沉溺保护三级）能否在**不牺牲解出率**的前提下降低 LLM Token 消耗？

## 2. 方法

- **设计**：A/B 对照，单因子（熔断 开/关）。
- **被试**：kpi9 诚实题集（`data/questions_real_kpi9/`，9 道 `real_*`，与 `KPI_BASELINE.json` 的 `offline_verified=9` 吻合）。本 run 取其中 8 道可自动解题目。
- **重复**：每臂 3 次（A1-A3 / B1-B3），满足 ≥3 种子 + 可复现。
- **指标**：`total_tokens`（真实用量）、`solved/total`、成本/解出率比。
- **统计**：均值 ± 样本标准差；95%CI 用 `mean ± 1.96·sd/√n`。

## 3. 结果

| 组 | 配置 | 运行 | total_tokens | solved/total |
|---|---|---|---|---|
| A_off | 无熔断 | A1 | 341,624 | 4/8 |
| A_off | 无熔断 | A2 | 345,637 | 4/8 |
| A_off | 无熔断 | A3 | 344,745 | 4/8 |
| B_on | 三级熔断 | B1 | 280,792 | 4/8 |
| B_on | 三级熔断 | B2 | 280,840 | 4/8 |
| B_on | 三级熔断 | B3 | 277,171 | 4/8 |

- A_off 均值 = **344,002** (sd 1,720；95%CI [342,055, 345,949])
- B_on 均值 = **279,601** (sd 1,718；95%CI [277,656, 281,546])
- **Token 节省 = 18.7%**（95%CI 近似 [17.7%, 19.7%]）
- **解出率 delta = 0**（4/8 = 4/8）

效应量稳定（sd < 0.6% 相对变异），无异常 run。

## 4. 与原假设的对话（诚实对账）

| 指标 | a priori 目标 | 底线 | 实测 | 判定 |
|---|---|---|---|---|
| Token 节省 | 40% | 20% | **18.7%** | 未达底线（差 1.3pp） |
| 解出率保持 | — | 不失分 | 4/8 = 4/8 | ✅ 完全保持 |

原 proposal 的 "-40%" 是**凭空设定的目标值、无基线**；实测以有基线、有重复的真值取代了它。结论更可信，但幅度低于原宣称。

## 5. 结论（可发表表述）

> **三级预算熔断在零解出率损失的条件下，降低约 18.7%（95%CI 17.7–19.7%）的真实 LLM Token 消耗。**

这是赛时 AICTF（预算/配额敏感场景）可直接采用的工程结论：**成本护栏不付出解题能力代价**。

## 6. 局限与威胁效度（不隐瞒）

1. **LLM 真推理贡献 = 0/9**：`by_solved_by.main_agent_llm.solved = 0`，9 题全由 presolve/工具链直出。熔断省下的 token 主要来自 presolve/工具调用链路，而非"LLM 思考"开销。结论对"工具密集型"题集稳健，对"纯 LLM 推理"题集的外推需谨慎。
2. **样本 = 8 题 × 3 重复**：题集规模小，效应估计稳健但题面多样性有限。
3. **无开放赛事**：结论来自离线真题集真链路，未在 live 平台验证（live `accepted=0`）。
4. **Claim 2/3 不可证伪**：依赖 LLM 路径被触发，而当前贡献 = 0，故错误归因 / 监督裁决的效应暂无法测量，暂缓。

## 7. 一句话给实战

熔断是"免费的成本护栏"——开着它，省 ~19% token，不失一题。赛时默认开启。
