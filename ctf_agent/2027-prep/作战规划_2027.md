# 2027 AI-CTF 作战规划（确定性优先框架·收口版）

> 基于 2026-09-29 实测真值收口。本规划**不美化**、**不把本地读数当平台 accepted**、**不把 presolve 算作 LLM 推理**。
> 引用任何 KPI 数字前，必须先 `import ctf_agent/scripts/_kpi_canonical.py` 取单一真值，**禁手抄**（见项目记忆第①条）。

---

## 0. 一句话定位

本框架是「**确定性优先的 CTF 静态分析器**」：held-out 上 presolve 确定性解出 **9/17**，主链路 LLM 自主推理实证 **≈0**。
2027 作战以**确定性能力为矛**、LLM 推理为锦上添花（不指望），目标窗口 = **不限省份的 AI-CTF 大类赛事**。

## 3. 作战目标（SMART，基于真实能力）

- **主线目标**：把确定性主链路（presolve）做成**可复现、可审计、可迁移**的静态分析框架。
- **量化目标（扩池后才有统计意义）**：
  - 扩池到 20+ 题后，以 **presolve 解出率**（分层：real vs external）作为唯一可引用能力指标。
  - LLM 主链路：承认 ≈0，**不立项"提升 LLM 推理"为主 KPI**（避免自欺）。
- **非目标**：不承诺 LLM 自主推理突破；不把本地读数等同平台 accepted（初赛 64 题 0 accepted 出局事实不变）。

---

## 4. 三路策略

### 4.1 确定性主链路强化（主矛，优先级 🔴 最高）
- **扩 presolve 路由**：当前 24 路由，缺口 38 项有测试守护 → 补强 flag 格式/明文识别/常见 crypto 静态特征。
- **降误杀**：`least-common-genominator` 类（presolve 命中却被 `--presolve-skip` 丢弃）已修，固化回归测试，禁止再次默认跳过。
- **题库/能力对齐**：misc 占语料 50% 但确定性解仅 4.3%，crypto 36%，**web 0/13、pwn 0/2 全灭**。→ 要么补 misc/web/pwn 静态路由，要么**承认非确定性强项区**，把题库重心调到 crypto。

### 4.2 LLM 主链路（锦上添花，低投入 🟡）
- 当前实证 ≈0，不主投。仅做：**E3 默认化实验**（每题 token 上升，须先估成本报授权）作为证据注入对照。
- 换强模型（claude/gpt 类）再测边际收益存疑（失败是"方向根本不对"，非算力不足），需另报预算授权，**不默认投入**。
- **不把"LLM 推理率"作为对外承诺指标**。

### 4.3 治理资产固化（可迁移，长期价值 🟢）
- KPI canonical（禁手抄单一真值）
- 文档闸（中英 README 同步、口径更正声明顶置、不删改原文）
- 反注水（sha256 闸门、flag_verify 防 `echo flag{}` 打印泄漏）
- lease + 第⑫道守卫（测试/实现分离提交，无后门）

## 6. 风险与诚实声明

- 🔴 **样本阶梯**：N=17 未达 30 阈值，扩池前不对外宣称能力率。
- 🔴 **统计显著**：presolve 9/17 含 external 难度异质（external 比 real 难 ~14–600×），必须分层报告，禁止混成一个率。
- 🟡 **本地读数≠平台 accepted**：初赛 64 题 0 accepted 出局事实不变。
- 🟡 **zkpok 留白**：0 token 未测，不计入"绝对证明能力=0"。
- ✅ **不美化原则**：对外叙事统一为「含失败复盘的确定性优先 CTF 静态分析框架，含有限 LLM 真实推理」。
