# 双矩阵竞速架构（2026-08-21 攻坚落地）

## 一句话
**LLM 矩阵（多模型写攻击代码） × 数学引擎矩阵（确定性秒解）并行竞速**——数学引擎作为第 0 号选手先行，命中即胜、跳过 LLM 推理；未命中才启动 LLM 矩阵深推理。9 道真库题数学引擎独立解出 8 道（89%），零 API 成本。

## 为什么这是"真正的多模型矩阵"

用户一句话点破（08:30）：项目原有 12+ 模型**全是 LLM**——它们擅长识别题型、写攻击代码，但 88-bit DLP 这类**确定性计算**（2^44 步）任何 LLM 都不会算。真正的矩阵必须异构：

| 矩阵 | 成员 | 擅长 | 不擅长 |
|------|------|------|--------|
| LLM 矩阵 | deepseek/qwen/glm/kimi/moonshot/tokenhub... | 题型识别、代码生成、逆向推理、web/pwn 利用链 | 2^44 步确定性计算 |
| 数学引擎矩阵 | CryptoToolkit 攻击链/rsa_fermat_factor/legendre/lfsr/多层解码/reverse 静态 | RSA 变种、编码、LFSR、二次剩余、UPX/字符串 | 需要人类经验的模糊题 |
| 计算引擎缺口 | Sage/PARI/index calculus | 88-bit+ DLP | 本机未装（赛中用 SageCell 在线） |

## 实现

### 新文件
- `agents/math_engine.py`：MathEngineMatrix 类，14 个注册引擎，统一 `solve(question) -> (engine, flag)`
  - crypto_multilayer / crypto_caesar / crypto_morse（编码古典）
  - rsa_chain（委托 CryptoToolkit 兜底：fermat/small_e/wiener/common_modulus/hastad/phi_known/phi_known_inv/裸行嗅探/LFSR 嗅探）
  - legendre / lfsr / reverse_static / misc_zip / coppersmith / lattice / ecb / ecm / dlp_bsgs
  - 引擎失败返回 None 不抛异常（竞速容错）
  - `_run_async`：循环安全调用沙盒（修复 asyncio.run 嵌套冲突）

### 修改
- `run.py build_race_solver`：race() 开头先跑数学引擎矩阵（timeout 30s），命中返回
  `provider=math_engine:<engine>`、validated=True；未命中才构建 LLM 竞速池
- `core/fallbacks.py build_reverse_fallback_script`：多附件遍历（reverse_js 的 flag 在第二个附件 index.html 注释里）

## DLP 边界（诚实声明）
- specialcurve2 需 88-bit 强素数 DLP：阶含 88-bit 大素因子（2q 或 q），BSGS 需 2^44 步
- sympy 实测 90s 超时；本机 Windows 无 Sage，cypari2/python-flint 编译失败
- 赛中对策：agent 跳过（386s 止损），操作员用 SageCell 网页版 `R(h2).log(R(2))` 秒解
- 详见 `docs/DLP_独立性声明.md`
