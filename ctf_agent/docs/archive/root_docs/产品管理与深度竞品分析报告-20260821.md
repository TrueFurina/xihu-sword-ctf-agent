## 1.2 产品架构总览（当前真实状态）

```
多道赛题 API ──▶ PlatformAPI 抽象层（list/get/create/access/附件/提交/重置/销毁）

              ┌─ 主解题 Agent（Plan-Act-Observe 推理内核，509 行）

  单页看板（进度/耗时/flag，轮询刷新）+ 统一 JSON 契约（flag/confidence/evidence/error/supervision）
```

**架构演化复盘（v1.0 → v2.0，值得写进答辩）：**

| 原设计 | 问题 | 现方案 | 决策价值 |
|--------|------|--------|---------|
| 5 个独立子 Agent | 复合题型边界模糊、11 天维护 5 套 Prompt 必半成品 | **1 主 1 监** + 领域工具包 | 复杂度守恒：把"5 套推理大脑"降为"1 套大脑 + 工具包"，工程可维护性 ×3 |
| 多模型竞速 | 简单题浪费、难题三模型都解不出，成本 2-3 倍 | **分级降级调度** | 成本可控，效果等价 |
| 模板缓存为核心 | 背题秒解≠AI 能力，评委不打分 | 降级为辅助 payload 生成 | 把创新点放在"推理纠错"而非"背题" |
| 结果级校验 | 模型不知道自己错哪，重试=重复错误 | **步骤级错误分类修正** | 这是全行业都缺的：多数方案盲目重试 |
| Grafana/gVisor/向量库 | 11 天必缩水成摆设 | 全砍，单页 HTML 看板 | 砍得果断，MVP 保核心 |

## 2.2 学术与开源竞品深度拆解

### 2.2.1 SageCTF / OpenSage（最强对手，UCSB + UC Berkeley，2026）
- **战绩**：DEF CON 34 CTF quals（48h）解 7 题拿 8 个 flag、1,743 分、**686 队中 top 5%**，超越所有自报"No AI/Low AI"的 175 队；50 题基准解 39 题 vs Claude Code 13 题（Claude Code 解的它全解）。
- **架构**：OpenSage ADK——运行时可自建子 Agent 组织、分层记忆、多模型编排（GPT-5.5 做根 Agent 规避安全对齐误伤 + Claude-Opus-4.6 干重活）；单题 10h 上限 / $200 预算；工具全（IDA/Ghidra/pwntools/angr/z3/sagemath/qemu）。
- **对我们的启示**：① 它的"运行时动态建 Agent"是下一代 ADK 方向，我们 1 主 1 监是"预定义拓扑"——复杂度维度不同，不构成直接竞争；② 它暴露了"无互动评判反馈 + 缺失细分领域知识"是失败主因——**我们的步骤级校验 + 34 skill 正是对症下药**，只是实现深度还不够；③ 它单题 5 小时，我们是 3 小时赛程，赛制决定了我们不需要它的深度。

### 2.2.2 D-CIPHER（NYU 多智能体，2025 SOTA 之一）
- **战绩**：NYU CTF Bench 19.0-22.0%（Claude 3.5 Sonnet）、Cybench 22.5%、HackTheBox 44%；对比基线 EnIGMA 13.5% / Claude 3.5 单智能体 13.0%。
- **架构**：Planner（规划）+ 多异构 Executor（执行）+ Auto-prompter（自动生成初始 prompt）+ 动态反馈环；把 200 道 NYU CTF 映射到 MITRE ATT&CK。
- **对我们的启示**：它是"1 主 + 多执行器"，我们是"1 主 + 1 监 + 工具包"——**我们的监督 Agent 概念上更接近它的 Planner 反思，但我们是轻量模型裁决（省钱），它是同模型（烧钱）**。答辩时这是"成本工程"论据。

### 2.2.3 CRAKEN（自反思 + RAG，2025）
- **战绩**：NYU CTF 21-22%（Self-RAG 21%，Graph-RAG 22%，SOTA 持平）。
- **架构**：知识检索增强（RAG）+ 自反思循环；证明"检索历史解法"能显著提升 crypto/forensics/web。
- **对我们的启示**：**34 个 skill 就是我们"离线版 RAG"**——把常见攻击模式沉淀为确定性脚本，比在线检索更稳更快。可考虑赛后补一个"解法知识库"进内存检索。

### 2.2.4 CTF-Dojo / Cyber-Zero（开源权重微调路线，2025）
- **战绩**：CTF-Dojo 用 658 道容器化 CTF + 拒绝采样微调，Qwen 系 32B 在 InterCode-CTF 达 83.5%（+23.5pt），NYU CTF 10.4%；Cyber-Zero-32B NYU CTF 13.5%。
- **结论**：开源权重模型微调后仍大幅落后前沿闭源（Claude-3.7 在 InterCode 86.8% / NYU 18.2% / Cybench 30.0%，均值 39%）。
- **对我们的启示**：微调路线 ROI 低（要造数据、要算力），我们走"闭源 LLM + 确定性 skill 兜底"路线是对的——**把知识沉淀在 skill 里而非模型参数里**，这是预算有限队伍的最优解。

## 2.6 模型能力基线（用数据说话）

**关键洞察**：我们主用的 DeepSeek 系在 CTF 基准上与前沿闭源差距仅约 9pt（30.3% vs 39%），但**成本差一个数量级**——"国产模型 + 分级调度 + skill 兜底"是性价比最优解，这就是我们产品的成本护城河。答辩时这句可以原样用。

## 2.7 差异化定位总结（答辩武器库）

```
我们的独特组合 = 没有任何一个竞品同时拥有：
  ① 1主1监轻量裁决（监督即战略，解题即战术）    ← 结构上像 D-CIPHER 但更省
  ② 步骤级错误分类 + 结构化修正（≤3 次收敛）    ← SageCTF 都没有
  ③ 分级降级模型调度（成本可控的解出率提升）    ← 全行业只有我们明确做
  ④ 全生命周期平台 API 抽象（未知规范零恐慌）   ← 工程化卖点
  ⑤ 多题并行 + 单页看板 + 白名单合规            ← 国内赛道原生适配
  ⑥ 34 个确定性 skill（离线 RAG，稳过在线检索） ← 对标 CRAKEN 但零延迟零费用
```

**一句话差异化**：SageCTF 证明"AI 能单题深挖到 top 5%"，我们证明"AI 能在 3 小时题海中稳定收割 60% 的简单题并止损难题"——**在西湖论剑的规则下，后者就是第一名方程。**
