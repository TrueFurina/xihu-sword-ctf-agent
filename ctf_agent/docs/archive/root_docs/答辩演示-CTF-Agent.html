3 条核心创新点（逐条对标开源短板）

创新点 1：三级预算熔断体系
对标缺陷：verialabs 多模型竞速成本翻 2-3 倍无护栏；SageCTF 每题 5 小时成本极高；多数项目无任何成本管控
✅ 自研 scheduler/budget.py：单题 token 上限（防死循环烧钱）+ 全局预算（防整场击穿）+ 重试硬上限（第三层兜底）+ 降级阈值（接近上限强制轻量模型）——行业首个完整分层成本护栏，直击 DeepSeek 涨价与 3 小时赛时预算风险
创新点 2：结构化错误归因 + 监督裁决双引擎
对标缺陷：D-CIPHER 论文自述 retries/loss of focus；多数项目"多智能体"只是角色拆分无真实反思；盲目重试 3 次=重复同一错误
✅ 自研 verify/ 五类错误分类（僵局/方向错/幻觉/工具失败/环境）+ error_category + key_info + suggestion 定向修正（不丢整段日志）+ 确定性规则兜底与轻量模型 AI 裁决——从"让模型自己悟"升级为"告诉模型错在哪、往哪改"
创新点 3：Windows 无 Docker 全兼容沙盒
对标缺陷：11 个开源项目全部依赖 Docker/Linux 工具链，Windows 无法运行；本机 Docker 不可用时开发直接停滞
✅ 自研 sandbox/ 子进程隔离 + 30s 超时 kill + UTF-16 防御性解码 + Python 替代工具（file_analyze 替代 strings/binwalk、stego_lsb 替代 zsteg）——唯一在无 Docker Windows 环境可完整运行的 CTF-Agent，工程容错直接可演示
