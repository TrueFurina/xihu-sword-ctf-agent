- 数学引擎/确定性链命中（crypto 基础题：ezmult 0.0s / filterrandom 3s / simplelegendre 1s）→ **0 秒级秒解，不烧模型额度**。
- 命中优先级：**确定性链 > 4 路 LLM 竞速**。模型只负责"指路"（识别题型 → 触发 skill），确定性链负责"执行"——这是矩阵最强组合。
- 竞速全败 → `_auto_advisor` 生成定向提示（已有机制兜底）。

### 4.5 L3 LLM 交叉复核：已否决，不要用

- 08:50 原型实测：胜出 flag 用 qwen3.7-plus 复核"是否合法 CTF flag"→ **3/6 准确率（随机水平）**：真 flag `hacking_for_fun` 被误判 NO、假 flag（deepseek 幻觉 ROT13）被误判 YES。
- **结论：LLM 无法区分"格式合法的真 flag"与"格式合法的假 flag"，L3 交叉复核否决，正式赛不启用。**
- 可靠护栏 = 现有三态校验（格式/乱码拦截）+ validated/accepted 双通道（平台权威）。
