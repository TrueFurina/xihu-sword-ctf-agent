## 一、竞品全景：两类对手

### 1.1 开源/学术竞品（GitHub 上的 Agent）

| 竞品 | 真实成绩（官方披露） | 核心优势 | 致命短板（对我方的机会） |
|---|---|---|---|
| **verialabs/ctf-agent** | BSidesSF 2026 第1名，**52/52 全解** | 并发多模型竞速 swarm、Docker 隔离、消息总线 | 依赖 CTFd 协议，与西湖论剑 dasctf API 不通用；成本/限流未披露 |
| **SageCTF (OpenSage)** | DEF CON 前 5%（39/50 vs Claude Code 13/50） | AI 自生成拓扑、层级记忆、多模型编排 | **每题平均 5 小时**——速度致命短板，不符合"速度碾压"赛事目标 |
| **hydra (iamkorun)** | 未披露 | pass@k 并行、30 playbook、watchdog + flag gate | 强依赖 Claude Code 生态、Docker |
| **D-CIPHER (NYU)** | NYU 22% / Cybench 22.5% / HTB 44% | 多智能体 planner+executor | 绝对解出率低、单轮循环效率不足 |
| **InterCode-CTF** | 基线 40%→95%（ReAct&Plan） | 交互式编码基准 | 难度已饱和、串行 |
| **CHYing-Agent** | 线上第 9、单日最高 15 题 | 双 Agent（顾问+主攻手）、Kali 真环境 | 初始架构过重被迫重构；并发深度有限 |

**关键判断**：开源标杆（verialabs）的真实成绩是 **52/52 全解**，且是"并发多模型竞速"——这是我们的**硬对标对象**。我们 13/15 的 presolve 覆盖在"静态可解"题型上不输它，但一旦进入"必须 LLM 推理"的题（web 逻辑漏洞、misc 复杂隐写），我们立刻归零，而 verialabs 靠多模型 swarm 能啃下来。

### 1.2 同届真人对手（西湖论剑选手群 838552505，159 人）

来自 `西湖论剑大赛选手群³·超级深刻深度分析报告.md`（1914 条消息离线分析）：

- **绝大多数选手还在入门层**：群内高频问题是"一个 Agent 是什么意思""subagent 算不算 agent""最多开几个靶机（3个）"——大量队伍连架构都没想清楚。
- **真正的强敌是少数**：
  - 矿大等富校：**学校报销 GPT pro 套餐**，模型预算无压力；
  - 清华/北理技术全栈选手："从底层镜像到上层 Agent 都懂""打包 6 个版本"，被标注为"技术最强选手之一"；
  - 有选手在研究"用 deepseek 做中转实际调 GPT"绕过模型限制——说明对手已经在钻规则缝隙。
- **规则争议点（决定超车合法性）**：
  - **一支队伍只能一个 Agent 接入平台答题**（安恒官方）；
  - subagent 是否算"Agent"仍有争议；
  - 官方明确：**"不鼓励人工引导，希望选手主要关注 agent 自身的解题能力"**；
  - 测试赛用白名单模型，正式赛可能放宽，但需提前适配。

**关键判断**：同届对手的"平均水平"远低于我们（他们还在问概念），但"头部少数"有资金 + 全栈能力 + 规则钻营，是真正威胁。我们的优势是**工程治理与诚实基准**（总账、诚实扫描、presolve 覆盖），劣势是**真实推理能力归零 + 初赛已出局**。

## 三、如何真正超过所有竞品（可落地路径）

> 前提：初赛已出局，唯一合法推进 = 跑真题集真实链路 benchmark + 补 web/misc 短板。以下路径分"今年的复盘价值"和"明年的夺冠打法"两层。

### 路径 A：补齐 LLM 真实推理（最高优先级，当前 0/2）

这是和 verialabs / 同届头部拉开差距的唯一真战场。presolve 覆盖是"死知识"，对手也能堆；**LLM 在未知题上的泛化推理**才是分水岭。

1. **死磕残留 2 题**（1 web + 1 misc）：把 `main_agent_llm` 接管失败的题做成专项复盘，定位是"工具链缺失"还是"提示词退化"还是"模型能力上限"。
2. **多模型竞速（抄 verialabs 但国产化）**：当前 baidu/qwen 双源已接，但真实推理贡献 0——说明不是"没接模型"，是"主 Agent 在难题上没真正推理"。需把重型模型（deepseek-reasoner / qwen-max-thinking）在 watchdog 升级链路里真正用起来，而非只在 presolve 失败后象征性重试。
3. **本土题型专属训练**（见 `专属针对性训练方案.md`）：国产 RSA 变种、中文 SSTI 过滤、zip 伪加密、流量自定义字段——这是开源竞品 100% 卡壳、同届头部也未必覆盖的**差异化拉分点**。

### 路径 B：并发竞速碾压（对标 verialabs 的 52/52）

- 当前 worktree 3 车道是骨架，需实测并发题量上限（verialabs 默认 10 并发）。
- 每题 pass@k 多模型并行（参考 hydra）：先拿到 flag 者胜，缩短单题耗时。
- 毫秒级测速埋点，决赛演示时是"速度碾压"的直观证据。

### 路径 C：把"工程治理"变成答辩杀手锏

这是同届对手几乎为零、开源竞品也没有的维度：
- 总账实时变更流 + 七门禁 + 租约 + 诚实扫描，直接回答评委最关心的"**可解释、可审计、不造假**"。
- 决赛答辩时，对手讲不清架构/答不出"你怎么证明没手工代打"，我们能现场调出总账和 benchmark 真值——这是 **Go/No-Go 评审里最硬的信任分**。

### 路径 D：规则钻营的合法边界（针对同届头部）

- 官方"一个 Agent 接入"——把"主 Agent + 监督者 + 题型子 Agent"设计为**单接入点下的内部编排**，不违反"一个 Agent"字面规定，吃满 subagent 争议红利。
- "不鼓励人工引导"——把人工价值压到"赛前架构 + 赛中监督止损"，而非实时喂答案，合规且符合赛事导向。

## 四、锐评总结

- **不要漂**：报 86.7% 必须附注"含 presolve 静态直出，LLM 真推理贡献 0/2"。否则就是初代注水 commit 的老路。
- **真正能超车的只有一条主线**：把 LLM 在 web/misc 未知题上的真实推理从 0 拉起来。静态覆盖、成本、治理我们 already 赢，但赢在"死知识"上不够——赛事比的是 Agent 自己解题的能力。
- **今年已出局，但资产值钱**：真题集 benchmark 真值体系 + 治理四层，是明年复赛/其他赛事可直接复用的底座。别再堆治理文档，去碰真实靶机和源码审计。
