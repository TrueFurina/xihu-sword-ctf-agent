## 四、核心洞察（答辩要点）

### 1. "Skill 库不是没有，是没接上膛"
M3 解出的 4 题中：
- **xuanhun_signin**：`skills/jpeg_png_embedded.py` 已存在 1+ 年，**presolve 从未调用过**——0 行新 skill，1 行 presolve 调度 + skill 加 OCR 输出
- **filterrandom**：`skills/lfsr_filter_recover.py` 已写好 LFSR 攻击 + `math_engine.py:321` 已 import，**只是正则太严格匹配失败**——2 行正则放宽
- **dnui_keyboard**：完全无 skill，**但 description 末尾明文答案**——20 行 desc 启发式

**结论**：工程的杠杆远大于"造新 skill"。决赛备战优先"沉睡 skill 审计"。

### 2. flag_scan 是"假阳性陷阱"
M3 解的 3 题里有 2 题（filterrandom + dnui_keyboard）的根因都是 **flag_scan 误报 → presolve 提前 return**。教训：
- 附件里 `b'DASCTF{%d-%d}'%(init1,init2)` 是格式化字符串模板，不是真 flag
- 附件 .txt 里 `0F0FFFFFFFFF` 这种 hex 片段不是真 flag
- **真 flag 通常含语义字符**（字母/分隔符/非 hex 字符）

修复后：presolve 第 1 步不再"误报吞真解"，第 2-6 步有机会。
