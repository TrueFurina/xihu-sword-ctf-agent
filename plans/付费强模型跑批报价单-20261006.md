## 1. 成本模型（可核查假设）

### 1.1 单题 token 硬上界 = 80K（代码验证）
- `config.py:142` `per_question_token_budget = 80000`（env `CTF_AGENT_PER_Q_BUDGET`）

### 1.2 in/out 配比（估算，敏感度见 §3.3）
- **输出硬顶**：`max_tokens=2000`/次 × ≤12 次（`CTF_AGENT_LLM_CALL_BUDGET`，默认 12）= **≤24K/题**

- **实测锚点**：glm-4-flash 7 题合计 **58,688 token**（含 3 题被墙钟取消记 0）；deepseek 轮 161K
- 本单采用 **in:out = 4:1**（agent loop 典型：上下文重投主导）

## 4. 推荐最小实验（供拍板）

### 方案 A（首选）：5 题 × **glm-4.7**（付费档，同题对照）
- **成本**：S2 **≈¥0.6** / S3 **≈¥1.3**（悲观 in:out=1:1 也仅 ≈¥2.0）
- **理由**：最便宜的强档；在 `_PROVIDER_MODEL_ALLOWLIST['glm']` 内（探针 200，不必担心被静默回退）；与上批 glm-4.5-flash **同 provider 同题**，可直接归因「限流 vs 能力」
- **命令**：
```bash
cd ctf_agent
export CTF_AGENT_LLM_PROVIDER=glm \
       CTF_AGENT_GLM_MODEL=glm-4.7 CTF_AGENT_GLM_HEAVY_MODEL=glm-4.7 \
       CTF_AGENT_LIGHT_MODEL=glm-4.7 CTF_AGENT_HEAVY_MODEL=glm-4.7 \
       CTF_AGENT_PER_Q_BUDGET=80000 CTF_AGENT_GLOBAL_BUDGET=400000 \
       CTF_AGENT_E3=1 CTF_AGENT_BUDGET_REFLECTION=1
.venv/Scripts/python.exe -m eval.benchmark \
  --questions-dir data/questions_ext_A5_20261001 --provider glm --wallclock 180 \
  --results-dir data/results/heldout_a5_glm47_paid_20261006 --limit 5 --concurrency 1
```
- **耗时**：约 10–15min（5 × 180s + 开销）

### 方案 B（对照/加码）：5 题 × **doubao-seed-2-1-pro**

- **命令**：`--provider ark`（ark 默认 model 即 `doubao-seed-2-1-pro-260628`，无需 env 覆盖），其余同上

### 建议执行序
