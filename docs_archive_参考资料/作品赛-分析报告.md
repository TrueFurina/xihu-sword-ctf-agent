## 三、可借鉴创意（从对标作品中提取）

### 3.1 技术/架构创意
| 创意 | 来源作品 | 可借鉴点 |
|------|---------|---------|
| **图记忆 + 自进化机制** | `WallBreaker` | 攻防推演中引入图结构记忆，Agent 能"记住"历史攻击路径 |

| **红队视角攻击面研究** | `智安哨` | 从红队视角主动发现 Agent 攻击面，而非被动防御 |

## 四、差异化切入点（我的项目 vs 竞品）

### 4.1 2025 攻防靶场 · 差异化
| 竞品做法 | 我的项目差异 | 优势 |
|---------|------------|------|
| `WallBreaker` 做"图记忆攻防推演" | 我做"双 Agent 回合制对抗 + 动态场景生成 + 量化评估" | 更完整的闭环（生成→对抗→评估） |
| `赤霄破阵` 做"ReAct + APG 渗透测试" | 我做"红蓝双角色对抗" | 双向对抗 vs 单向渗透，更拟真 |
| `InfoWar` 做"卡牌游戏化" | 我做"真实漏洞库 + 真实 LLM 决策" | 实战性更强，不是游戏 |
| 多数作品无量化评估 | 我有"攻击成功率/威胁分布/综合判定" | 评委可量化打分，差异化明显 |

**核心卖点**：**"生成→对抗→评估"完整闭环 + 真实 LLM 决策 + 量化可验证**

### 4.2 2026 安全研判 Agent · 差异化
| 竞品做法 | 我的项目差异 | 优势 |
|---------|------------|------|
| `LLM 驱动的可信安全运营智能体`（N0T） | 我做"预筛 + 研判 + 门控 + 记忆 + 审计"全链路 | 更深的工程化（10 阶段 vs 单点） |
| `一键智巡` 做"告警自动化" | 我做"误报剔除 + 置信度门控 + HITL" | 不只是自动化，还解决"误报"痛点 |
| `MCP-Sentinel` 做"工具调用护栏" | 我做"事件研判 + 多 Agent 协作 + Ledger 审计" | 更完整的安全运营闭环 |
| `AgentGuard` 系列做"行为监督" | 我做"预筛分流 + 记忆注入 + 三模式对比评测" | 有评测数据支撑（90% 通过率） |
| 多数作品无真实评测 | 我有"三模式对比 + 混淆矩阵 + 成本估算" | 用数据证明架构价值 |

**核心卖点**：**"预筛省 70% + 三模式对比证明 + 误报记忆 + 全链路审计"**
