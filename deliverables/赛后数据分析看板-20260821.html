⑦ 关键结论 — 数据说了什么

结论数据依据对决赛的含义
账面 ≠ 实战: 语料 74.3% / 真库 89% / 独立彩排 33% / 正式赛 0%四个口径逐级递减 0~89pp答辩与训练都必须用"真题口径", 语料口径作废
测试赛 7/7 是假信号corpus 题 = 语料同源, 预扫秒解决赛模拟必须用 unseen 真题
数据链路 = 生命线: 附件/靶机/题面缺一即 0 解出三层错配 → LLM 空输入 → 空转 3 小时preflight 验证脚本进铁律, 开赛前必须全绿
熔断机制缺失致命: 坏 provider 空转数十分钟16:48-17:00 全源 401/402熔断 + 备用源充值, 赛前 reset_circuits()
能力缺口是最终原因: 修好链路也解不出赛后 dry-run 前 0 解出; 人工也未解出用 32 道真题沉淀 skill, 目标先解出 5-8 题
幻觉防线有效: LLM 报 81 个 flag 全被拦截validated=0, flag_checker 全部拦截证明"只信 validated/accepted" 纪律有效
一句话: 正式赛 0 解出 = 工程链路断裂(已修) + 能力错配(未修); 决赛胜负手不在修 bug, 而在用手里 32 道真题 + 80+ 附件把 agent 真正教会。
