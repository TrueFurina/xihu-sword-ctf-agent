## 三、发现的问题列表

### 问题 #1（⚠️ 非阻断 / 建议工程师修）— run.py race 第 0 号选手绕过 presolve 去重
- **位置**：`run.py:361-397`（race() 第 0 号选手直调 `MathEngineMatrix.solve`）+ `core/presolve.py:138`（presolve 内 math_engine）
- **现象**：race 模式同一题 math_engine 最多被嗅探 2 次——第 0 号选手直调一次（不打 `_presolve_attempted` 标记），首个 LLM solver 的 presolve 内再跑一次（此后才打标记）。与 P1-3"统一 PreSolve 层、同一附件只嗅探一次"的收敛目标不完全一致（收敛了 5→2，未到 1）。
- **影响**：功能正确（两次结果一致，命中即秒解），仅最坏多花 ≤30s 引擎时间/题；非资源泄漏级问题。
- **修复建议**：race() 第 0 号选手改调 `await presolve(question, registry=..., sandbox=..., answers=...)`，或先检查 `presolve_attempted(question)` 再决定是否直跑；使去重标记统一生效。

### 问题 #2（⚠️ 提交前必处理 / 工程师操作）— `_verify_challenge_class.py` 幻影暂存 + 清理删除未暂存
