## 攻击链（lowe = 小指数 e=3 + 明文短 + 恰好跨 1 次模）

1. `pubkey.pem` → 极简 DER 解析 SPKI → (N, e=3)，N 为 1536-bit。
2. `key.enc` = 十进制大整数 `Y = K^e mod N`（K 为 512-bit 随机数）。
3. 关键性质：`N^(1/3) < K < (2N)^(1/3)` ⇒ `K^3 ∈ (N, 2N)` ⇒ `Y = K^3 − N` ⇒ **`Y + N` 是完全立方**。
   `K = iroot3(Y + N)`（现有 `_small_e_attack` 的 k 爆破在 k=1 命中，无需新代码）。
4. `file.enc` = base64(64B)；`secret = blob ⊕ K`（题面写 "C = Y xor S"，**实测是 K xor S**）。
