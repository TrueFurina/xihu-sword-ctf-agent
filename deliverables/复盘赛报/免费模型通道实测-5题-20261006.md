## 2. 结果：0/5（与 A5 同）——但**不可归因于能力**

| 指标 | 值 |
|---|---|
| 解出 | **0 / 5** |
| LLM 调用 | **55 次：200×17（31%） / 429×38（69%）** |
| 每题有效响应 | ~3.4 次（共 17 次） |
| 每题步数 | 3–4 步（远不足以解难题） |
| 熔断触发 | 0 次（瞬时限流未被误熔断） |
| ReadTimeout | 12 次；单步 >60s 超时 7 次 |

**判读**：agent loop 每题需数十次 LLM 调用，而免费档只放过 ~3.4 次/题 → agent 从未拿到公平出手机会。**0/5 是限流墙下的非可解释结果。**
`glm-4.7-flash` 更差（可用性小测 2/6，code 1305「访问量过大」）。
反差佐证：低频率小测 `glm-4.5-flash` 6/6 成功；真实 agent 高频 loop 下骤降至 31%。
