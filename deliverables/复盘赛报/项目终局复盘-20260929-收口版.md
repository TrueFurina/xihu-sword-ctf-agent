## 1. 项目是什么 / 为什么收口

- **立项**：AI Agent 解题夺旗（西湖论剑第 9 届 AI Agent 赛道），目标 API-only Agent 赛，不需手工 CTF。
- **初赛结局**：64 题 **0 accepted 出局**。
- **后续尝试**：反思后以 2027 不限省份 AI-CTF 为目标窗口，做确定性主链路强化 + LLM 推理探测。
- **收口原因（实测结论）**：held-out 上 **LLM 主链路自主推理实证 ≈0**，项目真实价值锚定在 **presolve 确定性静态分析**，不再以"LLM 推理突破"为叙事。

**③ 能力维度**
| 维度 | 进维度总数 | 解出 | 率 | 备注 |

### 2.3 读图
- **真实能力 = presolve 确定性静态分析**（real 100% / external 47% / 总 53%）。
- **LLM 主链路自主在 held-out 实证 0**——这是 8 道进主链路题（presolve 没命中的更难 external 题）全失败的实测事实。
- web/pwn 的 0 是**池子无题**，不可读作"能力差"。

## 3. LLM 自主推理为什么是 0（不是 bug，已逐项排除）

用户曾质疑"怎么还是 0"——下面是用四组跑批逐一排除的证据链：

| 假设 | 验证方式 | 结论 |
|---|---|---|
| 是早停机制误杀？ | B 方案：`CTF_AGENT_BUDGET_REFLECTION` 不设（OFF）+ 单题预算 200K（2.5×）重跑 8 失败题 | ❌ 仍 0/8；race_abandon 来自 FeedbackLoop/监督裁决，**非**省钱早停开关 |
| 是预算不够？ | mhk2/primes 给 200K（2.5×）仍硬顶烧穿失败 | ❌ 给再多 token 也解不出 |
| 是 E3 证据没进脑？ | M2：E3 ON vs OFF 对照（唯一变量），两组都 0/8 | ❌ E3 对解出零边际贡献 |
| 是只跑了子集？ | 8 道进主链路 external 题全部充分跑过（zkpok 在独立预算组补测 25,881 token/7 步） | ❌ 14 道 external 全失败，非漏测 |

**根因**：8 道失败题是 presolve 未命中的更难 external 题（crypto/misc），**单题难度比 presolve 解出题高约 600×**；主链路 LLM（deepseek-flash）在这批题上攻击链未命中、连续同动作空转，是**真实能力边界**，非工程缺陷。

**唯一留白**：zkpok 在 ceiling8（1.3M 全局预算）排第 8 位被连坐掐断 0-token；后在 M2 独立预算组已补测（25,881 token、7 步 race_abandon）——**0/8 现已闭环，无未测题**。

## 4. E3 工程优化（M2 结论，非能力项）

| 维度 | 结论 |
|---|---|
| 解出贡献 | **0**（ON/OFF 两组都 0/8） |
| 成本贡献 | **正向**：E3 ON 省 ~14% token（335,077 → 381,908，OFF 更费） |
| 质量贡献 | 防「证据不进脑」盲目重试（hwsim +79%、mceliece +149% 空转） |
| 机制 | E3 全文注入 plan prompt → LLM 更早聚焦攻击链、更早止损 |

**固化建议**：
1. 生产默认保持 **OFF**（`core/main_agent.py:160 e3_enabled=False`），避免对占多数的 presolve 题无谓增大 prompt。
2. Benchmark/评测保持 **强制 ON**（`scripts/benchmark_heldout.py:458`）——评测要测证据注入后表现，且实测更省 token。
3. **E3 归工程降本/防空转项，不写入"能力边界"叙事**。
