# 加载层 category 归一化 —— 接管外部题「能力不可达」系统性缺口

> 日期：2026-10-07 · 类型：零成本静态修复（无 LLM 调用） · 提交：`21036e8`（实现）+ `333ae0d`（测试） → `origin/main=333ae0d`
> 口径：本项目确定性能力接通，**不涉及 LLM 自主解题率**。

## 1. 问题（「能力存在但不可达」的系统性缺口）

外部题池（NYU/CSAW、cybench 等）产出**别名类别拼写**：

| 别名 | 出现池 | 数量 |
|---|---|---|
| `rev`（逆向） | questions_ext / A5 / A / cybench / trial5 | 24 |
| `forensics`（取证） | questions_ext / A5 / A / cybench / trial5 | 17 |

而 `eval/cases.py::Question.from_dict` 直读 `category` 字段**不做归一化**；下游一律按
`== "reverse"` / `in ("crypto","pwn","reverse")` **硬判**：

| 消费点 | 判定 | 受影响 |
|---|---|---|
| `presolve._try_reverse_route` | `cat != "reverse"` 直接 return | rev 题**跳过**逆向路由富化 |
| `main_agent._should_upgrade_heavy` | `cat in ("crypto","pwn","reverse")` | rev 题**不升重型模型** |
| `supervisor_agent` 步数上界 | 同上 → 25 否则 18 | rev 题只给 **18 步** |
| `decision_engine._HEAVY` | 同上 | rev 题**不进重型分配** |
| `phases.py` 兜底路由 | `category in ("reverse","pwn")` | rev 题**不走逆向兜底** |

即：**能力早已存在，但被类别拼写挡在门外**——合计 41 道外部题受影响。

## 2. 权威口径

规范类别集唯一来源 = `scripts/ingest_external_ctf.py:44 VALID_CATS`
= `("web","crypto","misc","reverse","pwn")`（该处 `forensics` 被判非法，与
`tests/test_heldout_external.py` 断言一致）。

映射方向依据：
- `rev → reverse`：与 `scripts/fetch_google_ctf.py` 的 `CAT_MAP` 同向（既有约定）。
- `forensics → misc`：与**本地库自身约定**一致——取证题（如
  `real_misc_longjian2023_baby_forensics3`）本就标为 `misc`。

## 3. 改法（单文件、单一入口）

`eval/cases.py`：
- 新增 `CANONICAL_CATEGORIES`（引用 VALID_CATS 口径）；
- 新增 `_CATEGORY_ALIASES`（rev/reversing/reverse-engineering→reverse；forensics/forensic→misc）；
- 新增 `normalize_category(raw)`：去空白+小写 → 命中别名映射 → 空值回落 misc →
  **未知类别原样返回**（不猜测，保留可观测性）；
- `Question.from_dict` 调用之（唯一中心构造器，覆盖 `load_questions` /
  `benchmark_heldout` / `_dryrun_race` 全路径）。

## 4. 实证（零 LLM 成本）

**gate 级对比**（`_try_reverse_route`）：
```
raw(rev)            category=rev      -> reverse_guidance 填充=False   ← 不可达
normalized(reverse) category=reverse  -> reverse_guidance 填充=True    ← 可达
```

**消费端可达性**：
```
raw=rev        -> norm=reverse   升重型=True   步数上界=25
raw=forensics  -> norm=misc      升重型=False  步数上界=18   （维持原状，无回归）
```

**全池安全扫描**（40 道 rev/forensics 题跑 presolve）：
- raw 类别 vs 归一化类别 → **逐条输出完全一致** ⇒ 本改动**零新增命中 / 零新增假阳性**。
- 扫描中出现 1 例 `NPF_{...}` 命中（cybench data_siege），**raw `forensics` 下同样出现
  = 既有现象，非本次引入**；且传真值（`flag_sha256`）时被 `_passes_answer_check`
  **正确丢弃**（实测 `answers=真值 -> None`）。属真值守卫正常行使，无需修复。

**回归**：新增 10/10；相关组合（load_questions/heldout/export/platform/qr）81/81；
pre-commit 快速回归 152/152。**零回归**。

**变异验证**：临时禁用 `from_dict` 归一化 → 3 个端到端用例必红、纯函数用例仍绿（符合预期）。

## 5. 诚实边界

- 本改动为**使能刀**：把「能力不可达」变「可达」，**不承诺解题数提升**；
  实际收益需真实跑批（走 LLM 链）验证，属后续事项。
- 归一是**加载时（内存对象）**，不改磁盘题库原始 JSON；`benchmark_heldout` 的
  泄露闸读原始 dict（故 forensics 不被误当 web/misc 泄露扫描——符合"取证答案本就在
  制品里"的预期）。
- `_stratify_external_benchmark.py` 读原始 JSON，TAXONOMY 报表仍显示源拼写，不受影响。
